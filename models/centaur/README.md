# Unified centaur MJCF
`centaur.xml` is the integrated AS2-W + R1-A7 floating-base artifact, renamed into English and made to share geometry under `../as2_w/meshes/` and `../r1_a7/meshes/`. It references 55 real external meshes; run `scripts/import_assets.py` before compiling. Its control, contact and placement have not been revalidated within this GitHub project.
