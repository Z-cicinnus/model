# 整机运动学、动力学与固定支撑工作空间

用户确认：空手、初始站姿、固定初始四轮地面支撑点。机身允许平移/升降。腰部只有yaw关节，因此躯干水平的工作空间与机身倾斜路径分开计算。冲击实验另见 impacts/impact_report.md。

整机质量 43.266282 kg；初始质心世界位置 [0.038751, -0.000166, 0.480382] m。
质量矩阵 (61, 61)，最小特征值 4.09607e-07；双臂/腿部经浮动基消元后的耦合矩阵范数 0.0923886。
NPZ保存完整质量矩阵、零速偏置力、刚体质心惯量、左右手6D雅可比、轮地接触雅可比和耦合矩阵。轮地雅可比使用实际圆柱最低点的全链速度，包含浮动基与所有腿/轮角速度；它不是只减去轮轴转速。
动力学方程：M·v̇+h=τ执行器+τ被动+τ接触+τ外力。质量矩阵含原文件armature；刚体质心惯量不含转子等效项。

## 正逆运动学

正解输出双手、四轮中心相对世界与底盘的4×4位姿。逆解以全部nv速度为变量，通过局部阻尼最小二乘与KKT等式保持四轮中心和手指耦合；缩放步长维持关节限位。它不是全局规划器，也不能证明任意目标不可达。
验证任务：双手保持朝向，前移20mm、升高15mm，底盘俯仰2°。结果：{'success': True, 'iterations': 4, 'position_error_m': 0.0001603403937044828, 'rotation_error_rad': 0.0003886266968784745, 'wheel_and_coupling_error': 9.14896301773549e-09, 'base_pose_error': 8.515228101951469e-05}。窗口ik回放为几何迭代，不是闭环动态控制。

## 五种腿高下的重力倾斜边界

按可行底盘高度范围等间距取5点，最低/最高端点包含在内。每个高度固定初始四轮地面支撑位置，腰/双臂保持零位，只调四条腿；逐一增加单轴俯仰或横滚，静力平衡需存在四个非负轮法向力，且所有电机关节力矩不超源模型上限。首个失败区间用二分细化；仅报告单轴角度，前后与左右组合可能更早失效。

限制角度由固定接触点的圆柱胎面/边缘几何、关节范围、支撑力与重力矩、执行器力矩共同决定，不等于移动底盘的动态防倾覆角。最低/最高为初始x/y不变的升降路径端点，不是允许平移后全局最低/最高高度。端点接近零的角度表示固定高度已没有调姿余量，不表示一倾斜就发生重力倾覆。analysis_data.npz中的height_tilt_qpos包含每个高度的水平状态和四个极限状态，可通过height_sweep模式逐一检查。
