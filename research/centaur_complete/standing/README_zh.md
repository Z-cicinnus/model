# 四轮足半人马：基础闭环站立控制

解压本增量包到已有 centaur_quadruped 目录；需已应用自碰撞和静力分析更新。本次不修改 XML、网格或安装位置。

```bash
python -m pip install -r standing/requirements.txt
python standing/run_standing.py --case hold --viewer
```

默认站立 30 秒后结束。运行全部测试：`python standing/run_standing.py --case all`。单项可选 hold、push_x、push_y、arms；--duration 指定秒数。默认 hold 30 秒，其余各 15 秒。

## 控制方法

统一整机静力分析的保持力矩作为常值前馈，33 个关节执行：τ = clip[τ₀ + Kp(qd−q) − Kd·q̇]。clip 按源 XML 力矩限值执行。静态前馈包含上部机构对整机支撑的影响；本版没有在线重算重力项、在线支撑力优化、积分或机身位姿反馈，不应称为 WBC/MPC。

| 关节组 | Kp N·m/rad | Kd N·m·s/rad |
|---|---:|---:|
| 底盘 hip/thigh/calf | 250 | 8 |
| 四轮角度保持 | 5 | 0.3 |
| 腰部 | 40 | 2 |
| 肩部与肘部 | 25 | 1 |
| 腕部 | 1 | 0.025 |
| 头部 | 2 | 0.05 |

从 static_support/results.json 读取初值和前馈，按执行器名称匹配。初始底盘高度约 0.423540 m、双肩外展 3°。模型 SHA-256 必须与静力分析记录一致；如果修改模型，需要重新运行 scripts/analyze_static_support.py。增益适用于当前仿真基线，不是硬件辨识结果。

基座保留 freejoint，轮地接触与自碰撞开启，body gravcomp 和 qfrc_applied 均为零。控制器只写 data.ctrl，不给机身添加向上支撑力。四轮采用角度 PD，不使用焊接或无限制刹车约束。

## 测试工况

- hold：空载水平地面原地保持。
- push_x / push_y：t=3.0–3.2 s 对底盘分别施加 +X / +Y 方向 30 N 水平力；其他时刻外力为零。
- arms：t=2–12 s，左右 shoulder_pitch 同步往返。目标偏移为 −0.15[1−cos(2π·0.1·(t−2))] rad，最大 0.3 rad（17.19°）；之后恢复原目标。微分反馈使用实际速度，未加目标速度前馈。仅验证该小幅肩部动作，不代表任意双臂任务。

MuJoCo 3.3.7，步长 1 ms，记录频率 100 Hz。验收阈值：俯仰/横滚 <2°，高度偏离初始值 <10 mm，水平位移 <30 mm，无力矩饱和、无超过 1 µm 的内部接触、无引擎警告。这是当前试验的工程阈值，不是理论稳定性证明。

## 使用边界

仍有毫米级位置偏移和小幅轮速振动，不保证受扰动后精确回到原位置。模型力矩限值不是已核实的连续额定力矩。结果不覆盖移动、转向、坡面、大范围操作或实机。

controller.py 为控制器，run_standing.py 为测试及可视化入口。results/*.json 为指标，*.npz 包含 samples 与 columns，记录时间、基座位置/姿态/速度、轮端法向力、控制力矩、关节误差和扰动力。基座平移速度为世界坐标，角速度遵循 MuJoCo freejoint 局部坐标定义；姿态为 xyz 欧拉角。

results/arms_replay.mp4 是已记录双臂测试状态的 25 fps 回放，不是另一轮动力学测试。render_replay.py 从基座状态、关节目标与误差重建姿态。重建命令：`python standing/render_replay.py --case arms`。仅录像需要 requirements_video.txt 中的依赖。

下一步可加入机身位姿反馈与在线支撑力分配，减小偏移，再推进移动和转向。

## 本次实测结果

| 工况 | 时长 s | 最大俯仰/横滚 ° | 最大水平位移 mm | 最大力矩占用 |
|---|---:|---:|---:|---:|
| 原地保持 | 30 | 0.0908 | 7.086 | 24.05% |
| 前后扰动 | 15 | 0.2772 | 13.260 | 24.58% |
| 左右扰动 | 15 | 0.2251 | 7.086 | 26.03% |
| 双臂动作 | 15 | 0.0768 | 7.086 | 24.25% |

四项均无饱和或内部碰撞；全部已记录样本的四轮法向力均大于 1 N，此接触统计仅代表 100 Hz 采样结果。原地保持末尾 x≈−6.258 mm，z≈0.422919 m，俯仰≈−0.0904°。最后 1 秒四轮平均载荷约 [107.900,107.857,98.971,99.206] N。软接触和控制反馈使其与理想静力分配略有差异。

双臂测试中，左右肩 pitch 的最大跟踪误差约 3.13°，因此该结果只说明已测试动作下能够维持站立，不代表高精度双臂轨迹跟踪。
