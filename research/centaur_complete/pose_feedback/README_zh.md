# 机身位置与偏航反馈

在 standing 基础控制器的静态力矩前馈及 33 关节 PD 上，增加基座纵向位置、纵向速度、偏航角及偏航角速度反馈，调节四个轮电机力矩。四轮原先的角度位置反馈关闭，保留轮速阻尼。机器人仍是浮动基座，支撑由地面接触产生。

在基座偏航角为 ψ 时，纵向位置 e = cosψ·x + sinψ·y，纵向速度 v = cosψ·vx + sinψ·vy。四个轮的共同附加力矩为 clip(−100e−14v, ±4 N·m)；偏航差动项为 clip(40ψ+3ωz, ±3 N·m)，左轮加、右轮减。最终按电机限值裁剪。角速度 ωz 是 MuJoCo freejoint 的机身坐标系角速度分量；小姿态角附近作为偏航角速度近似。设定点是世界原点及零偏航。

当前控制器直接读取仿真基座真值，无噪声、延迟或状态估计。横向位置没有直接闭环；四轮的侧滑和地面摩擦影响偏航控制。本版没有在线支撑力优化，不是完整六自由度位姿控制、WBC 或可直接部署的实机控制器。

## 运行

在完整包 centaur_quadruped 目录安装 `python -m pip install -r requirements.txt`，运行：

```bash
python pose_feedback/run.py --case hold --viewer
python pose_feedback/run.py --case all
python pose_feedback/run.py --case yaw
```

`--case all` 包含 hold（30 秒）、push_x、push_y、arms（各 15 秒）；yaw 单独运行 15 秒。正负方向由模型坐标定义。原站立控制器保留，执行 `python standing/run_standing.py --case hold --viewer` 可作比较。模型和静力分析的 SHA-256 不一致时脚本会拒绝运行，需重新进行静力分析和控制验证。

## 仿真与结果

MuJoCo 3.3.7，步长 1 ms，记录 100 Hz。位置、姿态、关节状态为仿真真值。X/Y 水平扰动为第 3 秒起 30 N、0.2 秒；yaw 工况为世界竖直轴外加 5 N·m、0.2 秒；双臂为原站立控制测试中两个肩 pitch 关节同时缓慢偏移最多 0.3 rad 的往返动作。除指定扰动外，不对基座施加外力或虚拟支撑，qfrc_applied 全程为零。

| 工况 | 测试时长 | 最大水平位移 | 最大横滚/俯仰 | 结束时 x/y 位置 mm |
|---|---:|---:|---:|---|
| 原地站立 | 30 s | 1.453 mm | 0.150° | 0.129 / -0.001 |
| X 扰动 | 15 s | 5.145 mm | 0.379° | 0.310 / 0.000 |
| Y 扰动 | 15 s | 3.769 mm | 0.325° | -0.254 / 0.259 |
| 双臂动作 | 15 s | 2.324 mm | 0.081° | -0.152 / -0.001 |
| 偏航扰动 | 15 s | 1.197 mm | 0.157° | -0.245 / -0.003 |

偏航扰动峰值 0.265°，15 秒末约 0.023°。原地站立的结束时 x 偏移从旧控制器 −6.258 mm 降至 0.129 mm；X 扰动时从旧版 6.542 mm 降至 0.310 mm。相同 X 扰动下最大俯仰/横滚从旧版 0.277° 增至新版 0.379°，表明位置恢复与瞬态姿态之间存在权衡。

四个原工况按照上一版验收标准：横滚/俯仰 <2°、高度变化 <10 mm、水平位移 <30 mm、无力矩饱和、无内部碰撞及仿真警告；偏航工况另要求偏航峰值 <5°、结束时绝对值 <1°。五项测试均通过。指标是这些工况下的仿真结果，不能外推为所有载荷、地形与扰动均稳定，也未验证实机。轮载接触仅按 100 Hz 记录，力矩上限采用 XML 限值，未验证连续额定能力。

results 含各工况 JSON 汇总和 NPZ 时间序列，字段定义沿用 standing；yaw 力矩及持续时间记录在 yaw.json，NPZ 最后三列仅记录线性外力，不能把全零线性外力误认为没有偏航扰动力矩。
