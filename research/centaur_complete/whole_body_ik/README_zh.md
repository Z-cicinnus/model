# 第3项：全身逆运动学 QP 与力矩 PD 基线

运行：`python whole_body_ik/run.py --case all`。单项可选 hold、arms、coordinated；可加 `--viewer`。使用已有 numpy/scipy/mujoco 依赖，不需要新增QP包。脚本先规划12秒参考，再进行浮动基座动力学仿真。没有开启在线重规划：QP沿参考状态求解，PD使用实际关节反馈。

## 任务

三项均12秒，前2秒保持；2–10秒按 sin² 平滑往返；最后2秒保持。arms：左右腕部原点同时向世界X前方、Z上方移动，最大各15 mm，保持初始腕部朝向，基座目标位置与姿态保持初值。coordinated：相同双腕任务，同时机身目标绕世界Y轴俯仰0–1°–0°。hold：全部保持。腕部原点不是夹爪TCP，没有物体、抓取或行驶。

机身姿态目标为预设协调任务，不是算法自主选择的最优姿态；双臂、机身、四腿变量在同一39维优化中求解，没有拆分两个机器人。

## QP

每20 ms在参考状态计算全身雅可比，求解 min 1/2 ||A v-y||²，采用SciPy SLSQP求解此凸二次目标与线性等式、区间约束。A叠加两个腕部线速度（缩放10）、角速度（缩放2）、基座线/角速度（缩放10）与正则项0.03I。任务速度为位姿误差乘4；各任务是加权软目标，没有严格层级优先级。正则项使H=AᵀA正定。

硬等式：四轮当前材料接触点速度等于接触位置误差乘5；四轮轴速度为零。该约束用于原地协调操作，不适用于滚动行驶。轮体上的接触材料点取已有静力分析结果，固定在轮体局部系；此小范围任务使用该近似，未来滚动需更新接触模型。有限积分后可能有微小漂移。

硬区间：基座平移速度±0.04 m/s、角速度±0.15 rad/s、各关节±0.5 rad/s；根据源模型关节限位减去1e-4 rad裕量计算下一步速度界。速度值为本实验设定，不是硬件额定值。未加入自碰撞距离不等式；仅验证生成参考与实际仿真无内部穿透，不保证任意输入安全。

参考状态经 mj_integratePos 积分，保持浮动基座四元数定义。参考接触点雅可比用于逐帧计算准静态四轮竖直载荷及重力保持力矩；关节指令为 tau_ff + Kp(q_ref-q) + Kd(v_ref-v)，沿用 standing 的33关节增益、执行器映射和限幅。该前馈忽略参考加速度和速度耦合项，适用于本次慢动作。没有全身逆动力学力矩QP，也没有摩擦锥优化。

实际仿真只写33个执行器ctrl；无虚拟支撑、无浮动基座锁定、无外加机身力矩。接触、自碰撞和重力保持开启。轨迹中机身姿态由腿部关节动作与轮地接触实现，不直接修改实际qpos。

## 输出与验收

results/*_reference.npz：50 Hz参考qpos/qvel、前馈、末端/机身任务目标及dt；*_actual.npz：100 Hz实际qpos和误差、姿态、轮载等时间序列，columns给出字段定义。*.json为指标。QP状态失败会立即终止；验收失败会返回非零退出状态。

事先固定的本阶段阈值：双腕世界位置误差各<20 mm，机身俯仰跟踪误差<0.5°，横滚<1°，水平漂移<30 mm，高度误差<10 mm，采样四轮法向力>1 N，无内部碰撞、力矩饱和、引擎警告。阈值只用于基础验证，20 mm不能视为高精度抓取能力。

三项正式测试均通过。组合任务实际俯仰峰值约0.952°，最大俯仰跟踪误差0.131°，双腕最大误差分别8.38/8.69 mm；最大水平漂移约7.08 mm。腕部最大误差主要来自原地保持阶段的基座偏移和关节弹性误差，未做末端在线闭环修正。最大力矩占限值24.13%，最小采样轮载91.36 N。参考和实际均未发现超过1µm的内部穿透；参考检查50 Hz、实际碰撞检查每仿真步，轮载记录100 Hz。

这是第3项的原地小范围协调基线：已完成全关节PD、全身速度级IK QP与双腕运动配合机身姿态调整的仿真验证。它不是实时闭环全身控制器，也不代表抓取、行驶、任意大范围姿态或实机验证。第4项的统一移动操作任务集仍待建立。
