# 整机静态支撑力与关节保持力矩

本次只新增分析脚本和结果，不改模型、安装位姿或碰撞设置。基于centaur_self_collision.xml 的 home（双肩外展 3°），无额外载荷、水平地面、四个点接触。MuJoCo 3.3.7。

## 计算方法

静止时采用整机方程 g(q) = Bτ + Jᵀf。g 为全身重力广义力，B 为执行器到广义力的映射，J 为四个轮地接触点的平动雅可比。本模型输出端 motor 的 gear=1，因此 ctrl 单位为 N·m。

本次接触力仅取竖直向上分量，切向力及接触力矩均为零；浮动基座的前六行用于求支撑力，剩余各关节行用于求保持力矩。四轮载荷分配存在冗余，采用满足平衡且最接近平均载荷的解：min ||f−(mg/4)1||²，约束 Af=g_base。以伪逆求解后检查所有支撑力非负、力和力矩残差、关节限位和执行器限值，不把该分配解释为唯一真实载荷。

接触位置使用微小下移 0.1 mm 的几何查询得到，再投影到地面 z=0；正式计算姿态恢复到近似几何相切高度。qpos 已写入 results.json，此值是理想刚性接触静力初值，不是 MuJoCo 软接触的平衡解。

## 验证与适用边界

浮动基座平衡方程最大残差 8.882e-16，合力矩残差范数小于 1e-6 N·m。将计算的理想接触广义力与执行器力矩输入前向动力学，最大加速度绝对值为 2.953e-15（平移 m/s²、旋转 rad/s²）。验证时只在内存中关闭接触求解器，以免与外加理想接触力重复计入；未保存到 XML，未将该步骤当作稳定站立试验。

下一步使用这些力矩作为前馈初值，开发关节反馈与机身姿态控制，在实际轮地接触求解器开启、浮动基座不固定的条件下验证。初始轮地接触建立、软接触形变和反馈调节可能使真实载荷与本次分配不同。

将本增量包解压到原 centaur_quadruped 目录，运行 `python scripts/analyze_static_support.py` 可重算 results.json。需要 numpy、scipy 和 mujoco；本次没有重新打包原模型或网格。
